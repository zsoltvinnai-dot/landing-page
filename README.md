# ANITA — Art of Beauty

Statikus, reszponzív bemutatkozó oldal 3D „Beauty Orbit” látványvilággal és szerkeszthető JavaScript-alapú árlistával.

## Helyi indítás

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Ezután: `http://127.0.0.1:4173/`

## Szerkesztés

- Tartalom és oldalstruktúra: `index.html`
- Arculat, 3D és reszponzív megjelenés: `styles.css`
- Árlista és interakciók: `script.js`
- Hivatalos Anita-képek: `assets/`

Az árlista piaci háttere az `ARLISTA-JAVASLAT.md` fájlban található.
